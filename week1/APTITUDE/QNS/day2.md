# Day 2 – Aptitude: Averages

## 1. What is an Average?

An average is a single value that represents a group of numbers.

**Example:**

Find the average of 10, 20 and 30.

Average = (10 + 20 + 30) / 3

Average = 60 / 3

**Answer: 20**

## 2. Important Average Formulas

1. Average = Sum of Values / Number of Values
2. Sum of Values = Average × Number of Values
3. Number of Values = Sum of Values / Average
4. New Average after Adding a Value = (Old Sum + New Value) / New Count
5. New Average after Removing a Value = (Old Sum - Removed Value) / New Count
6. Combined Average = (Sum of All Groups) / (Total Number of Values)
7. Missing Value = Required Total - Sum of Known Values
8. New Average after Replacement = (Old Sum - Old Value + New Value) / Number of Values

## 3. Practice Questions with Solutions

### Question 1: Find the average of 10, 20, 30, 40 and 50.

**Solution:**

Step 1: Add all the numbers.

10 + 20 + 30 + 40 + 50 = 150

Step 2: Count the numbers.

There are 5 numbers.

Step 3: Apply the formula.

Average = Sum / Count

Average = 150 / 5

**Answer: 30**

---

### Question 2: The average of 5 numbers is 20. Find their total sum.

**Solution:**

Formula:

Sum = Average × Number of Values

Substitute:

Sum = 20 × 5

**Answer: 100**

---

### Question 3: The average of 4 numbers is 25. Three numbers are 20, 30 and 40. Find the fourth number.

**Solution:**

Step 1: Find the total sum.

Sum = Average × Count

Sum = 25 × 4 = 100

Step 2: Add the known numbers.

20 + 30 + 40 = 90

Step 3: Find the missing number.

Missing Number = Total Sum - Known Sum

= 100 - 90

**Answer: 10**

---

### Question 4: The average age of 5 students is 20 years. One more student aged 26 joins them. Find the new average.

**Solution:**

Step 1: Find the original total age.

20 × 5 = 100

Step 2: Add the new student's age.

100 + 26 = 126

Step 3: Calculate the new average.

New Average = 126 / 6

**Answer: 21 years**

---

### Question 5: The average of 6 numbers is 30. One number, 40, is removed. Find the new average.

**Solution:**

Step 1: Find the original sum.

30 × 6 = 180

Step 2: Remove the given number.

180 - 40 = 140

Step 3: Calculate the new average.

New Average = 140 / 5

**Answer: 28**

---

### Question 6: The average of 5 numbers is 20. The number 10 is replaced by 30. Find the new average.

**Solution:**

Step 1: Find the original sum.

20 × 5 = 100

Step 2: Remove the old number.

100 - 10 = 90

Step 3: Add the new number.

90 + 30 = 120

Step 4: Calculate the new average.

120 / 5 = 24

**Answer: 24**

---

### Question 7: The average marks of 20 students is 60. The average marks of another 30 students is 70. Find the combined average.

**Solution:**

Step 1: Find the total marks of the first group.

20 × 60 = 1200

Step 2: Find the total marks of the second group.

30 × 70 = 2100

Step 3: Add the total marks.

1200 + 2100 = 3300

Step 4: Find the total number of students.

20 + 30 = 50

Step 5: Calculate the combined average.

3300 / 50 = 66

**Answer: 66 marks**

---

### Question 8: Find the average of 7 consecutive numbers: 11, 12, 13, 14, 15, 16 and 17.

**Solution:**

For consecutive numbers with an equal gap, the average is the middle number.

The middle number is 14.

We can also calculate:

Average = (11 + 12 + 13 + 14 + 15 + 16 + 17) / 7

Average = 98 / 7

**Answer: 14**

---

### Question 9: The average of 5 numbers is 40. If every number is increased by 5, what will be the new average?

**Solution:**

When the same value is added to every number, the average increases by that value.

Old Average = 40

Increase = 5

New Average = 40 + 5

**Answer: 45**

---

### Question 10: The average of 4 numbers is 25. The average of another 4 numbers is 35. Find the combined average.

**Solution:**

Step 1: Find the first group's total.

4 × 25 = 100

Step 2: Find the second group's total.

4 × 35 = 140

Step 3: Add both totals.

100 + 140 = 240

Step 4: Find the total count.

4 + 4 = 8

Step 5: Calculate the combined average.

240 / 8 = 30

**Answer: 30**

## 4. Important Average Properties and Shortcuts

### Property 1: Adding the Same Number

If the same number is added to every value, the average increases by that number.

Example:

Original average = 20

Add 5 to every value.

New average = 20 + 5 = 25

### Property 2: Subtracting the Same Number

If the same number is subtracted from every value, the average decreases by that number.

Example:

Original average = 50

Subtract 10 from every value.

New average = 50 - 10 = 40

### Property 3: Multiplying Every Value

If every value is multiplied by a number, the average is also multiplied by that number.

Example:

Original average = 10

Multiply every value by 3.

New average = 10 × 3 = 30

### Property 4: Dividing Every Value

If every value is divided by a number, the average is also divided by that number.

Example:

Original average = 60

Divide every value by 2.

New average = 60 / 2 = 30

### Property 5: Combined Average

When combining groups, do not simply take the average of group averages unless both groups have the same number of values.

Use:

Combined Average = (Group 1 Total + Group 2 Total) / (Group 1 Count + Group 2 Count)

### Property 6: Consecutive Numbers

For consecutive numbers with equal gaps, the average is the middle value.

Example:

Average of 21, 22, 23, 24 and 25 = 23.

### Property 7: Sum of Deviations

The sum of the differences between each value and the mean is always zero.

## 5. Common Mistakes

1. Forgetting to count all values.
2. Dividing by the wrong number of values.
3. Using the old count after adding or removing a value.
4. Taking a simple average of group averages when group sizes differ.
5. Using the new value instead of the original value in replacement questions.
6. Confusing average with total sum.

## 6. Quick Formula Revision

| Question Type | Formula |
|---|---|
| Basic average | Sum / Count |
| Find total | Average × Count |
| Find missing number | Required Sum - Known Sum |
| Add a value | (Old Sum + New Value) / New Count |
| Remove a value | (Old Sum - Removed Value) / New Count |
| Replace a value | (Old Sum - Old Value + New Value) / Count |
| Combined average | Combined Sum / Combined Count |
| Consecutive numbers | Middle value |
| Increase every value by x | Old Average + x |
| Decrease every value by x | Old Average - x |
