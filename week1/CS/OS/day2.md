## 1. What is an Operating System?

An Operating System (OS) is system software that manages computer hardware and software resources and provides services to application programs.

Examples:

- Windows
- Linux
- macOS
- Android
- iOS

Think of the OS as a manager between applications and computer hardware.

1\. Process management

A process is a program currently being executed.

Example: When you open Chrome, the OS manages its running process.

2\. Memory management

Manages RAM allocation for running programs.

Example: Chrome and VS Code both need RAM. The OS manages their memory usage.

3\. File management

Manages files and folders.

Examples: Creating, reading, writing, renaming and deleting files.

4\. Device management

Manages communication between the OS and hardware devices.

Examples: Keyboard, mouse, printer, monitor and storage devices.

5\. System calls

A system call allows a program to request a service from the OS kernel.

Examples:

- Opening a file.
- Reading a file.
- Writing a file.
- Creating a process.
