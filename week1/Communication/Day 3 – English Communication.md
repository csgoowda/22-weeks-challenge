# Day 3 – English Communication

**Date:** 5 November 2026  
**Duration:** 15 Minutes  
**Topic:** Daily Stand-up Update – Built, Blocked, Next

---

## 1. What is a Daily Stand-up?

A daily stand-up is a short meeting in software development teams.

Developers share updates about their work, problems and upcoming tasks.

A stand-up update usually has three parts:

1. Built
2. Blocked
3. Next

## 2. Built – What did you complete?

Use this section to explain what you completed.

**Useful sentences:**

- I completed...
- I finished...
- I implemented...
- I learned...
- I practised...
- I worked on...

**Examples:**

- I completed Python loops and functions.
- I implemented a factorial calculator.
- I practised digit sum and prime number problems.
- I learned basic SQL queries.
- I studied computer networking concepts.

## 3. Blocked – What problems did you face?

Use this section to explain any difficulties or problems.

**Useful sentences:**

- I am facing an issue with...
- I had difficulty understanding...
- I need some help with...
- I am still learning...
- I couldn't complete...

**Examples:**

- I had some difficulty understanding time complexity.
- I am facing an issue with SQL queries.
- I need some help understanding database transactions.
- I am still learning Python functions.
- I couldn't complete one programming exercise.

If you don't have any problems, say:

"I don't have any blockers."

## 4. Next – What will you work on next?

Use this section to explain your upcoming tasks.

**Useful sentences:**

- Next, I will work on...
- Today, I will practise...
- I plan to complete...
- I will improve...
- My next task is...

**Examples:**

- Next, I will practise SQL queries.
- Today, I will solve more DSA problems.
- I plan to improve my Python programming skills.
- I will work on my backend project.
- My next task is learning database concepts.

---

## 5. Complete Stand-up Update Example

Imagine you are working as a Python Backend Developer.

**Built:**

Yesterday, I completed Python loops and functions. I also practised factorial, digit sum and prime number problems.

**Blocked:**

I had some difficulty understanding time complexity, but I am practising it.

**Next:**

Today, I will practise SQL queries and improve my understanding of computer networking concepts.

## 6. Useful English Vocabulary

| Word | Meaning |
|---|---|
| Completed | Finished something |
| Implemented | Developed or added a feature |
| Practised | Repeated something to improve |
| Blocker | A problem stopping progress |
| Issue | A problem |
| Improve | Become better |
| Upcoming | Something planned for the future |
| Resolve | Solve a problem |
| Implement | Put an idea into practice |
| Progress | Development or improvement |

---

## 7. Common English Sentence Patterns

| Situation | Sentence |
|---|---|
| Completed work | I completed the task. |
| Current work | I am working on the task. |
| Future work | I will complete the task. |
| Difficulty | I am facing a problem. |
| Asking for help | Could you help me with this? |
| Explaining progress | I have made good progress. |
| Reporting completion | The task has been completed. |
| Reporting delay | I couldn't finish the task yesterday. |

## 8. Speaking Practice

Prepare your own daily stand-up update using these three sections.

**Built:** What did you complete today?

**Blocked:** What was difficult for you?

**Next:** What will you study or build next?

Try to speak for 30–60 seconds.
