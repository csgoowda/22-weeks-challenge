## Day 2 – English Communication

Your next task is to explain Operating Systems (OS) in your own words.

Imagine you are explaining it to a junior student who knows very little about computers.

### Your task

Write 5–7 simple sentences covering:

1. What is an Operating System?
2. Why do we need an OS?
3. What is process management?
4. What is memory management?
5. What is file management?
6. What is device management?
7. What are system calls?

Example opening:

"An Operating System is system software that manages computer hardware and software resources."

Now continue in your own English. Don't worry about grammar mistakes. I'll correct your sentences and explain how to improve them.
