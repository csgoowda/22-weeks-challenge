# Day 2 – Aptitude: Averages

## 1. Introduction

An average is a value that represents a group of numbers.

**Basic Formula:**

Average = Sum of all values / Number of values

**Example:**

Find the average of 10, 20 and 30.

Sum = 10 + 20 + 30 = 60

Count = 3

Average = 60 / 3 = **20**

### Important Basic Formulas

- Sum = Average × Number of values
- Average = Sum / Number of values
- Number of values = Sum / Average

## 2. Types of Average Problems

### Type 1: Find the Average

**Question:** Find the average of 15, 20, 25, 30 and 35.

Solution:

Sum = 15 + 20 + 25 + 30 + 35 = 125

Count = 5

Average = 125 / 5

**Answer: 25**

### Type 2: Find the Total Sum

**Question:** The average marks of 12 students is 65. Find their total marks.

Formula:

Sum = Average × Count

Solution:

Sum = 65 × 12

**Answer: 780**

### Type 3: Find the Missing Number

**Question:** The average of 5 numbers is 20. Four numbers are 10, 15, 25 and 30. Find the fifth number.

Solution:

Required total = 20 × 5 = 100

Known total = 10 + 15 + 25 + 30 = 80

Missing number = 100 - 80

**Answer: 20**

### Type 4: Average After Adding a Number

**Question:** The average of 4 numbers is 30. A new number, 50, is added. Find the new average.

Solution:

Old total = 30 × 4 = 120

New total = 120 + 50 = 170

New count = 5

New average = 170 / 5

**Answer: 34**

Formula:

New Average = (Old Average × Old Count + New Value) / (Old Count + 1)

### Type 5: Average After Removing a Number

**Question:** The average of 5 numbers is 40. One number, 60, is removed. Find the new average.

Solution:

Old total = 40 × 5 = 200

Remaining total = 200 - 60 = 140

Remaining count = 4

New average = 140 / 4

**Answer: 35**

Formula:

New Average = (Old Average × Old Count - Removed Value) / (Old Count - 1)

### Type 6: Replacement of a Number

**Question:** The average of 8 numbers is 25. The number 32 is replaced by 48. Find the new average.

Solution:

Old total = 25 × 8 = 200

Change in total = 48 - 32 = 16

New total = 200 + 16 = 216

New average = 216 / 8

**Answer: 27**

Shortcut:

New Average = Old Average + (New Value - Old Value) / Number of values

### Type 7: Average of Two Groups

**Question:** Four workers produce an average of 18 units each. Six other workers produce an average of 23 units each. Find the combined average.

Solution:

First group total = 4 × 18 = 72

Second group total = 6 × 23 = 138

Combined total = 72 + 138 = 210

Total workers = 4 + 6 = 10

Combined average = 210 / 10

**Answer: 21**

Formula:

Combined Average = (n1 × A1 + n2 × A2) / (n1 + n2)

Important: When group sizes are different, do not simply calculate the average of the two group averages.

### Type 8: Average of Consecutive Numbers

**Question:** Find the average of 11, 12, 13, 14 and 15.

The middle number is 13.

**Answer: 13**

For an odd number of consecutive integers, the average is the middle number.

**Example:**

The average of 7 consecutive integers is 31. Find the largest integer.

Numbers:

28, 29, 30, 31, 32, 33, 34

Largest number = **34**

For an even number of consecutive integers, the average is the average of the two middle numbers.

Example:

10, 11, 12, 13

Average = (11 + 12) / 2 = **11.5**

### Type 9: Average Increase or Decrease

**Question:** The average of 10 students is 50. A student scoring 70 joins. Find the new average.

Solution:

Old total = 10 × 50 = 500

New total = 500 + 70 = 570

New count = 11

New average = 570 / 11

**Answer: 51.82 approximately**

Shortcut:

New Average = Old Average + (New Value - Old Average) / New Count

Here, New Count means the count after adding the new value.

### Type 10: Average Age Problems

**Question:** The average age of 5 people is 24 years. A new person aged 30 joins. Find the new average age.

Solution:

Old total age = 5 × 24 = 120

New total age = 120 + 30 = 150

New count = 6

New average = 150 / 6

**Answer: 25 years**

The same method works for marks, salaries, ages and production quantities.

### Type 11: Average of Equal Groups

**Question:** Two groups each contain 5 students. Their average marks are 60 and 80. Find the combined average.

Since both groups have equal sizes:

Combined average = (60 + 80) / 2

**Answer: 70**

When two groups have equal sizes, their combined average is the simple average of their individual averages.

### Type 12: Weighted Average

A weighted average considers the importance or weight of each value.

**Question:** A student gets 80 marks in an exam carrying 40% weight and 60 marks in another exam carrying 60% weight. Find the weighted average.

Formula:

Weighted Average = Sum of (Value × Weight) / Sum of weights

Solution:

= (80 × 40 + 60 × 60) / 100

= (3200 + 3600) / 100

= 6800 / 100

**Answer: 68**

## 3. Important Average Properties and Shortcuts

| Situation | Effect on Average |
|---|---|
| Add the same number to every value | Average increases by that number |
| Subtract the same number from every value | Average decreases by that number |
| Multiply every value by a number | Average is multiplied by that number |
| Divide every value by a number | Average is divided by that number |
| Change the order of values | No change |
| Remove a value above the average | Remaining average decreases |
| Remove a value below the average | Remaining average increases |
| Add a value above the average | New average increases |
| Add a value below the average | New average decreases |

### Important Mathematical Property

The sum of deviations from the arithmetic mean is always zero.

Example:

Numbers = 10, 20, 30

Average = 20

Deviations:

- 10 - 20 = -10
- 20 - 20 = 0
- 30 - 20 = 10

Sum of deviations = -10 + 0 + 10 = **0**

## 4. Practice Questions with Solutions

### Question 1

The average of 6 numbers is 15. Find their sum.

Solution:

Sum = 15 × 6

**Answer: 90**

### Question 2

The average of 8 numbers is 24. If one number is 30, find the average of the remaining seven.

Solution:

Old sum = 8 × 24 = 192

Remaining sum = 192 - 30 = 162

New average = 162 / 7

**Answer: 23.14 approximately**

### Question 3

The average of 4 numbers is 18. A fifth number is added and the new average becomes 20. Find the fifth number.

Solution:

Old sum = 4 × 18 = 72

New sum = 5 × 20 = 100

Fifth number = 100 - 72

**Answer: 28**

### Question 4

The average of 9 numbers is 40. One value of 50 is replaced by 32. Find the new average.

Solution:

Old sum = 9 × 40 = 360

New sum = 360 - 50 + 32 = 342

New average = 342 / 9

**Answer: 38**

### Question 5

The average age of 12 people is 30. A person aged 42 leaves. Find the remaining average age.

Solution:

Old total = 12 × 30 = 360

Remaining total = 360 - 42 = 318

Remaining count = 11

New average = 318 / 11

**Answer: 28.91 years approximately**

### Question 6

The average of 3 numbers is 20 and the average of 5 other numbers is 30. Find the average of all 8 numbers.

Solution:

First group sum = 3 × 20 = 60

Second group sum = 5 × 30 = 150

Combined sum = 210

Combined average = 210 / 8

**Answer: 26.25**

### Question 7

The average of 5 consecutive odd numbers is 21. Find the largest number.

Solution:

Middle number = 21

Numbers = 17, 19, 21, 23, 25

**Answer: 25**

### Question 8

A batsman scores 40, 60, 50 and 70 runs in four innings. How many runs must he score in the fifth innings to average 55?

Solution:

Required total = 55 × 5 = 275

Existing total = 40 + 60 + 50 + 70 = 220

Required score = 275 - 220

**Answer: 55 runs**

## 5. Common Mistakes to Avoid

1. Dividing by the wrong number of values.
2. Forgetting to update the count after adding or removing a value.
3. Taking a simple average of two groups with different sizes.
4. Forgetting to subtract the removed value from the total.
5. Confusing weighted average with ordinary average.
6. Rounding too early during calculations.
7. Selecting only one answer in a multi-select question when multiple answers are correct.

## 6. Important Formula Sheet

| Problem | Formula |
|---|---|
| Basic average | Sum / Count |
| Total sum | Average × Count |
| Number of values | Sum / Average |
| Add a value | (nA + x) / (n + 1) |
| Remove a value | (nA - x) / (n - 1) |
| Replace a value | A + (x - y) / n |
| Two-group average | (n1A1 + n2A2) / (n1 + n2) |
| Weighted average | Sum of (weight × value) / Sum of weights |

Where:

- A = Original average
- n = Original number of values
- x = New or added value
- y = Replaced or removed value
- n1, n2 = Group sizes
- A1, A2 = Group averages
